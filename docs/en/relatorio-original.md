# The original "Independent Expert Report", point by point

> **Scope of this page.** The text of the original document (8 pages, anonymous) was not provided to this session. The claims below come from the **summary** prepared in an earlier session. Claims not present in that summary were not assessed. If the PDF is delivered, this page must be reviewed against the text.

Criterion for the "Reproduces?" column: **yes** = the report's number comes out exactly from the official data; **no** = it does not; **n/a** = not a testable number. The "Conclusion supported?" column assesses the inference, not the number.

**Summary.** Of the report's numbers that are testable against official data, those that are counts (339,593 sections, 8.6 million, the Bahia percentages, the unanimous sections) reproduce. The conclusions the report draws from them do not hold: eligible voters are not votes, manual voter release is not a vote and did not grow, the Bahia difference changes sign across states and vanishes within the same polling place, and unanimity does not exceed 2022.
